# corso-coding-agentico-slide

Slide e fogli di lavoro del corso di coding agentico per i colleghi informatici dell'ITTS "Belluzzi-Da Vinci".

Sito: https://thomascasali.github.io/corso-coding-agentico-slide/

Questo repo è pubblico e contiene solo ciò che si può mostrare ai partecipanti: l'indice del corso, le slide
(HTML autonomi) e i fogli di lavoro in pagina e PDF. Il resto del lavoro, comprese soluzioni e note per il docente,
vive in un repo privato. **Non modificare i file a mano**: il contenuto viene copiato dallo script
`scripts/pubblica-slide.sh` del repo privato.

Tutti i dati e il codice degli esercizi sono inventati.
