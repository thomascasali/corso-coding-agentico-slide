Scheda: lo stesso compito con due agenti

Si lavora in coppia, sul PC del laboratorio, nella palestra (prenotazione dei laboratori, dati inventati).

Obiettivo: vedere che cosa dipende dallo strumento e che cosa dal modello. I due agenti parlano con lo stesso proxy, quindi con lo stesso modello: le differenze che noti sono dello strumento.

Prima di partire

Incolla i comandi uno alla volta:

git status

git switch -c lavoro-a10 partenza-a10

Le istruzioni di progetto sono già a posto: AGENTS.md contiene il testo e CLAUDE.md lo importa, quindi Claude Code e OpenCode leggono le stesse regole. Nella cartella .claude/ ci sono anche la skill, il subagente e l'hook dei test degli argomenti 8 e 9: annota quale dei due strumenti li usa.

Il compito

Incollalo uguale in tutti e due gli agenti:

Aggiungi alla pagina web della palestra un filtro per laboratorio: una tendina in public/index.html e il parametro ?lab= in GET /api/prenotazioni. Scrivi un test in test/server.test.js e dimmi come hai verificato che funziona.

1. Claude Code

  1. Apri Claude Code nella cartella della palestra, in una sessione nuova.
  2. Dai il compito. Mentre lavora, annota nella tabella ogni richiesta di conferma.
  3. A lavoro finito, git status e git diff: segna quanti file ha toccato.
  4. Scarta tutto: git restore . e cancella i file nuovi che git status mostra.

2. OpenCode

  1. Apri il file di configurazione di OpenCode del laboratorio (te lo indica il docente) e leggi le sezioni permission, share e autoupdate. Annota che cosa chiede e che cosa nega.

  2. Apri OpenCode nella stessa cartella. Parti con l'agente Plan (tasto Tab) e chiedi un piano per il compito, senza eseguirlo.

  3. Passa a Build e dai il compito. Annota ogni richiesta di conferma.

  4. Come prima: git status, git diff, scarta tutto.

3. Il confronto

Claude Code OpenCode
Richieste di conferma (quante, per che cosa)
Comando usato per i test

Poi rispondi in due righe:

  • Quale dei due ti ha lasciato più controllo, e per merito di quale impostazione?
  • Cosa succederebbe a un collega meno esperto se OpenCode fosse usato senza la configurazione del laboratorio?
