Scheda: sistemare le istruzioni della palestra

Si lavora in coppia, sul PC del laboratorio, nella palestra (prenotazione dei laboratori, dati inventati). Durata indicativa: 30 minuti.

Prima di partire

git status
git switch -c lavoro-a4 partenza-a4

Il punto partenza-a4 ha due file di istruzioni: CLAUDE.md e AGENTS.md. Sono corti di proposito.

1. Il compito di prova (prima)

Apri Claude Code nella cartella della palestra e dai questo compito, copiato così:

Aggiungi al comando "elenco" l'opzione --max N, che mostra al massimo N prenotazioni.
Scrivi un test e dimmi come hai verificato che funziona.

Annota nella tabella in fondo: quale comando ha usato per i test, se ha toccato dati/dati.json, se ha creato file nuovi. Poi scarta le modifiche con git restore . (e cancella gli eventuali file nuovi: git status li mostra).

2. Cosa ha capito

In una sessione nuova (/clear) chiedi:

Quali istruzioni di progetto hai caricato? Citale e dimmi da quale file vengono.
Dove stanno i dati e come si lanciano i test?

Con /context all (voce «Memory files») controlli quali file sono caricati davvero; /memory li elenca e li apre.

3. Trova gli errori

Leggi CLAUDE.md e AGENTS.md riga per riga. Per ogni percorso e comando nominato, controlla che esista (ls, prova il comando). I due file dicono le stesse cose? Che cosa manca di ciò che l'agente ha dovuto indovinare?

4. Scrivi istruzioni migliori

  • Correggi ciò che è sbagliato.
  • Aggiungi comandi, convenzioni e divieti che servono davvero (usa la checklist).
  • Tieni una fonte sola: un file contiene le istruzioni comuni, l'altro le importa con @.
  • Resta sotto le 40 righe in totale: è una palestra, non un manuale.

5. Lo stesso compito (dopo)

Sessione nuova, stesso testo del punto 1. Confronta con quanto avevi annotato.
