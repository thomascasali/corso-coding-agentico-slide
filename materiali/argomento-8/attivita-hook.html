Scheda: uno hook che blocca un comando

Si lavora in coppia, sul PC del laboratorio, nella palestra (prenotazione dei laboratori, dati inventati). Durata indicativa: 35 minuti per i passi 1-4, circa 15 minuti per il passo 5 (facoltativo).

Prima di partire

git status
git switch -c lavoro-a8 partenza-a8

Nel punto partenza-a8 ci sono docs/esercizio-hook.md (la consegna), scripts/prova-hook.js (la batteria di prove) e una cartella .claude/hooks/ vuota.

1. Leggi la consegna

Apri docs/esercizio-hook.md. Scrivi su un foglio, prima di toccare il codice:

  • quali comandi lo hook deve fermare;
  • quali comandi deve lasciar passare;
  • con quale codice di uscita si blocca e dove va scritto il motivo.

2. Scrivi lo hook

Crea .claude/hooks/blocca-comandi.js. Lo hook legge il JSON dallo standard input, prende tool_input.command, e decide. Usa il promemoria per il formato dell'evento e per i codici di uscita.

Parti da poche regole e aggiungile una alla volta. Puoi chiedere aiuto all'agente, ma la regola la decidi tu: leggi il codice che ti propone prima di accettarlo.

3. Provalo senza l'agente

node scripts/prova-hook.js .claude/hooks/blocca-comandi.js

Lo script manda allo hook dieci comandi e dice se il comportamento è quello atteso. Obiettivo: dieci prove su dieci.

Poi aggiungi tu due comandi alla batteria (uno da bloccare scritto in un modo diverso, uno da lasciar passare che somiglia a uno vietato) e guarda se lo hook regge.

4. Collegalo a Claude Code

Crea o completa .claude/settings.json con il blocco hooks del promemoria, poi:

  1. riavvia la sessione di Claude Code, o controlla con /hooks che lo hook compaia sotto PreToolUse;
  2. chiedi all'agente di eseguire un comando che dovrebbe essere bloccato;
  3. premi Ctrl+O e guarda che cosa ha ricevuto l'agente, e come ha reagito.

Annota nella tabella qui sotto che cosa è successo.

5. Facoltativo: un server MCP di sola lettura

Serve Node.js 24 o più recente (node --version). Se non c'è, salta questo passo.

  1. Crea una cartella cartella-prova e mettici due file di testo con contenuto inventato.
  2. Collega il server (comando nel promemoria) con ambito local, non project.
  3. In Claude Code apri /mcp: il server deve risultare connesso.
  4. Chiedi all'agente di elencare i file della cartella e di riassumerne uno.
  5. Chiedigli di scrivere un file nella cartella. Che cosa risponde? Perché?

Quando hai finito, rimuovi il server: claude mcp remove documenti.
