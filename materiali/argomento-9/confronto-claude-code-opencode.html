Scheda: lo stesso compito con due agenti

Si lavora in coppia, sul PC del laboratorio, nella palestra (prenotazione dei laboratori, dati inventati). Durata indicativa: 30 minuti.

Obiettivo: vedere che cosa dipende dallo strumento e che cosa dal modello. I due agenti parlano con lo stesso proxy, quindi con lo stesso modello: le differenze che noti sono dello strumento.

Prima di partire

git status
git switch -c lavoro-a9 partenza-a9

Per far leggere le stesse istruzioni ai due agenti, porta nella cartella i due file corretti dell'argomento 4: AGENTS.md con le istruzioni e CLAUDE.md con la sola riga @AGENTS.md. Se hai ancora il ramo lavoro-a4, puoi copiarli da lì.

Il compito

Copialo uguale per tutti e due gli agenti:

Aggiungi al comando "elenco" l'opzione --lab, che mostra solo le prenotazioni di un laboratorio.
Scrivi un test e dimmi come hai verificato che funziona.

1. Claude Code

  1. Apri Claude Code nella cartella della palestra, in una sessione nuova.
  2. Dai il compito. Mentre lavora, annota nella tabella ogni richiesta di conferma.
  3. A lavoro finito, git status e git diff: segna quanti file ha toccato.
  4. Scarta tutto: git restore . e cancella i file nuovi che git status mostra.

2. OpenCode

  1. Apri il file di configurazione di OpenCode del laboratorio (te lo indica il docente) e leggi le sezioni permission, share e autoupdate. Annota che cosa chiede e che cosa nega.

  2. Apri OpenCode nella stessa cartella. Parti con l'agente Plan (tasto Tab) e chiedi un piano per il compito, senza eseguirlo.

  3. Passa a Build e dai il compito. Annota ogni richiesta di conferma.

  4. Come prima: git status, git diff, scarta tutto.
